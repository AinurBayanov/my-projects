Основные проекты
1. Оценка эффекта открытия отделения банка в Волгограде (синтетический контроль)

Командный проект Школы по прикладной статистике (кафедра матстатистики МГУ и Лаборатория прикладной статистики Т-Банка), февраль 2026.

Задача: оценить, как открытие отделения повлияло на 7 продуктовых метрик, когда A/B-тест невозможен. Данные по 20 городам до и после открытия.
Что сделано: подготовка и очистка данных, отбор 5 городов-доноров, синтетический Волгоград (регрессия с ограничениями на веса), проверка предпосылок модели, t-тесты с поправкой Бонферрони, плацебо-валидация на 4 городах.
Методы: синтетический контроль, регрессионный анализ, проверка гипотез, множественные сравнения.
Материалы: папка Школы по статистике/

2. Оптимизация числа запусков тестов при проверке релизов

Командный проект Школы по прикладной статистике (кафедра матстатистики МГУ), октябрь 2026.

Задача: для 40 тестов выбрать число запусков каждого, минимизируя стоимость при вероятности пропустить проблемный релиз не более 5%.
Что сделано: модель со скрытыми состояниями, оценка параметров методом максимального правдоподобия, сведение к задаче целочисленного линейного программирования (scipy.optimize.milp, HiGHS), проверка параметрическим бутстрепом.
Методы: метод максимального правдоподобия, MILP, бутстреп, кросс-валидация.
Материалы: папка Школы по статистике/
